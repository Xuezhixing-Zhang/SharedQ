### Settings

In this section, we propose three simulation designs to evaluate the performance of our Q learning model with three goals: 

- I. Show that our method can exhibit less bias for those shared parameters. Even when mis-specified, the bias generated by fused ridge can be tolerated.
- II. Show that our method can serve as a more flexible choice compared to conventional Q learning and Q learning with mixed effects, in terms of less biased estimate, better assignment and more flexibility.
- III. Show that our method is not biased when there is no shared parameter.

For each setting, we consider a sample size 100, 300, 500 and 1000. 

#### Setting III - Continuous Covariates, 3 stage 

##### Primary Outcome

Linear model, shared decision rule and shared confounder, 3 stage:

$$
\begin{aligned}
Y_1 &= \gamma_1 + \gamma_2 O_1 + \gamma_3A_1 + \gamma_4O_1A_1 + \epsilon_1\\
Y_2 &= Y_1 +\frac{3}{2}[\gamma_5O_1 + \gamma_6A_2 + \gamma_7O_2A_2+\gamma_{8}A_1A_2] + \epsilon_2\\
Y_3 &= Y_2+3[\gamma_{9}O_1 +\gamma_{10}A_3 + \gamma_{11}O_3A_3 +\gamma_{12}A_2A_3+\gamma_{13}A_1A_2A_3] + \epsilon_3\\
Y_{primary} &= R_1Y_1 + (1-R_1)R_2(\frac{Y_1+Y_2}{2}) + (1-R_1)(1-R_2)(\frac{Y_1+Y_2+Y_3}{3})
\end{aligned}
$$

where $\boldsymbol\gamma$ denotes the true parameters for generating primary outcomes at each stage. 

$A_1, A_2, A_3$ are treatment assigned at each stage, where $P[A_j = 1] = P[A_j = -1] = \frac{1}{2}$.  Responders at stage $j$ will be assigned to $A_{j+1} = -1$ at next stage.

$O_j$ is a time-varying continuous covariate generated as $O_1 \sim N(0,1), O_2= \delta_{21}O_1 + \delta_{22}A_1 + \epsilon_{O1}, O_3 = \delta_{31}O_2 + \delta_{32}A_2 + \delta_{33}A_1A_2 + \epsilon_{O2}$, where $\delta_{21} = 0.6, \delta_{22} = 0.5, \delta_{31} = 0.5, \delta_{32} = 0.4, \delta_{33} = 0.6,\epsilon_{O1} \sim N(0,1^2), \epsilon_{O2} \sim N(0,1^2)$.

Responders are randomly selected at each stage, with $P[R_1 = 1] = 0.38$ and $P[R_2 = 1] = 0.19$, which are the same as settings in the Q-Shared paper.

The Q models are
$$
\begin{align*}
Q_3 &= \beta_{30} + \beta_{31}O_1 + \beta_{32}A_1 + \beta_{33}O_1A_1 + \beta_{34}O_2 + \beta_{35}A_2 \\
&\quad + \beta_{36}O_2A_2 + \beta_{37}A_1A_2 + \beta_{38}O_3 + 
\left( \psi_0 + \psi_1O_3 + \psi_2A_2 + \psi_3A_1A_2 \right) A_3, \\
\\
Q_2 &= \beta_{20} + \beta_{21}O_1 + \beta_{22}A_1 + \beta_{23}O_1A_1 + \beta_{24}O_2 \\
&\quad + \left( \psi_0 + \psi_1O_2 + \psi_2A_1 \right) A_2, \\
\\
Q_1 &= \beta_{10} + \beta_{11}O_1 + \left( \psi_0 + \psi_1O_1 \right) A_1.
\end{align*}
$$

The shared parameter situations include:

- $\psi_1 = \mu_1 +\delta_1, \delta_1 \sim N(0, \sigma_1^2)$
- $\psi_2 = \mu_2 +\delta_2, \delta_2 \sim N(0, \sigma_2^2)$
- $\psi_3 = \mu_3 +\delta_3, \delta_3 \sim N(0, \sigma_3^2)$

$\sigma$ indicates how the shared parameters may differentiate from each other, when $\sigma = 0$, the parameters are exactly shared. Misspecified SQlearning and QShared method will be applied according to this scenario. You may consider try multiple different $\sigma$ when running the simulation, to better show how our methods perform under those shared pattern. My suggestion is to try $\sigma = 0, \sigma=0.1, \sigma=0.3$, but the true specification should be depend on the true parameter magnitutes. You may record you specification of $\sigma$ when running simulations.



#### MCMC for Simulation data generating

Instead of knowing the exact parameter for data generating, we want to directly specify the vector $\boldsymbol \psi$ for Q learning.

- First, specify the vector $\boldsymbol \psi$. 

- Let $\boldsymbol \gamma$ be the parameters used to generate primary outcomes for each stage. Start with a random $\boldsymbol \gamma$ and generate a large Monte Carlo dataset without random errors. In this case, we expect to use this large dataset to represent the true Q values we should have (the sum between average outcomes from responders and max(Q) value of next stage from non-responders).

- With these "true" Q values, we inversely calculate the $\boldsymbol \psi$ from our proposed model structure (run regressions). Of course the $\hat {\boldsymbol \psi}$ is not we specified in the first step. Now we can construct an objective function based on this:

  - $$
    L(\boldsymbol \gamma) = ||\hat {\boldsymbol \psi} - \boldsymbol \psi||^2_2
    $$

- Now the question becomes find $\boldsymbol \gamma$ that minimize the objective function. To ensure the identifiability, we put a constraint $||\gamma||_2^2 = 1$ or some constraints on the domain of $\boldsymbol \gamma$ for a narrower searching area.

IMPORTANT: When running nloptr to obtain the true estimates, do remember to adjust the search interval by adjusting the constraints within the code files to obtain the values desired. After obtaining true estimates, double check the shared parameter to see if it really shares (exhibits similar values in you specification) like what you expect.
